## 先把三个词说清楚：BGP、IPLC、高防

这三个词经常被商家混着用，实际指向的东西不一样。

**BGP** 是一种路由协议。对用户来说，“厦门 BGP 入口”的实际意义是：厦门本地电信、联通、移动三网用户都能比较直接地连到这个入口，不需要绕路，也不太受单运营商互联互通质量波动的影响。

**IPLC** 指国际私有租用线路，本质是点对点的跨境物理专线。它和走公网的“优化线路”最大的区别在于：流量不经过公共互联网跨境段，不受跨境拥塞和针对公网链路的 QoS 限制影响，稳定性和延迟表现是另一档水平。

**高防** 指 DDoS 防护。MKCloud 的厦港产品默认含 100Gbps DDoS 高防，防御能力可以付费定制升级，还可以申请开通针对海外攻击与 UDP 攻击的防护模式。

把这三样叠在一起——“IPLC 物理隔离 + 独享带宽 + 厦门 BGP 三网入口 + 100G DDoS 高防 + 无跨省 QoS 限制”——就是这条产品线的核心卖点，也是它价格明显高于普通 VPS 的原因。

## 这条线实际怎么用？有一个关键限制

MKCloud 的高防专线交付形态是 VPS，每台机器分配 **1 个独立入口 IP 和 1 个独立出口 IP**。用法是：你从本地通过 RDP 或 SSH 连接厦门入口，业务程序在机器里运行，流量从香港出口向外访问。

注意一个很多人下单前没搞清楚的点：**香港出口不支持外部连入**。也就是说这条线是“由内向外出站”的通道，不能拿来当公开网站服务器、游戏服务端或接收外部回调的入口。它的定位是给你自己的业务程序提供一个干净的跨境出站通道，而不是搭一个对外的服务。

官方知识库还明确了一点：端内参考延迟 1~2ms 来自产品资料，指的是入口到出口这段，**不等于你本地宽带到香港目标网站的全程延迟**。本地到入口那段的质量取决于你家宽线和接入条件，下单前最好用本地网络实际测试。

- **跨境电商 ERP 与店铺运营**：多人同时操作后台、抓取订单、同步库存，需要的是稳定而非峰值，独享不限流量的计费方式对这种 24 小时挂着的使用模式比较友好。

不适合的场景前面已经说过，再强调一次：**对外提供服务的业务（建站、公开 API 入口、游戏服务端）不合适**，因为香港出口不接受外部连入。建站需求应该去看常规的香港服务器产品。

## 常见问题

**厦门 BGP 到香港的延迟到底是多少？**
官方给的端内参考值是 1~2ms，即厦门入口到香港出口这段。你实际感受到的延迟 = 本地宽带到厦门入口 + 1~2ms + 香港出口到目标站点的耗时。厦门本地用户前一段通常只有几毫秒，全程体验会非常接近本地操作。

**没有 SLA，出问题怎么办？**
默认套餐不承诺 SLA，需要可用性保障要在购买前沟通定制。日常问题通过工单处理，这类型产品的响应速度和服务质量建议先从小档位合作验证。

**能先买一个月试试吗？**
可以按月付开通，但注意退款只覆盖质量问题且需要举证。如果不确定线路是否满足业务要求，月付测试一段再决定长期周期，比直接季付年付稳妥。

**厦港和泉港怎么选？**
两者都是福建到香港的高防 IPLC 独享款，区别在入口：厦港走厦门 BGP 入口，泉港走泉州电信入口。选哪个主要看你本地到哪个入口的宽带质量更好，可以从实际宽带测试结果出发，而不是默认选便宜的那个。

**这个价格还有议价空间吗？**
